# Clínica MEPSO – Sistema de gestión

Prototipo en Java (Swing) para gestionar pacientes, médicos y citas de la Clínica MEPSO.

## Paradigmas
- Programación orientada a objetos
- Programación funcional (filter, map, reduce)
- Programación orientada a eventos

## Cómo ejecutarlo
1. Abrir el proyecto en Eclipse con Java 21.
2. Ejecutar `Ingreso.java` (usuario `admin`, contraseña `123456`).
